파일 선택

      광고 자리영상 광고16:9 · 소리 없이 자동 재생되는 형태

      사용 방법

      1. 파일을 끌어다 놓거나 선택합니다.
      2. 변환하기 버튼을 누릅니다.
      3. 완성된 파일을 다운로드합니다.

      파일 형식 알아보기

      AVIF는 최신 이미지 형식으로 같은 화질에서 용량이 매우 작지만, 지원하는 프로그램이 아직 많지 않습니다.

      PNG는 화질 손실 없이 저장하는 형식으로 투명 배경을 지원해 로고·캡처 화면에 많이 쓰입니다. 사진은 JPG보다 용량이 커지는 편입니다.

      자주 묻는 질문

      파일이 서버에 올라가나요?

      아니요. 변환은 내 브라우저 안에서만 처리되고, 파일은 어디로도 전송되지 않습니다.

      무료인가요? 횟수나 용량 제한이 있나요?

      무료이고 회원가입도 필요 없습니다. 횟수 제한은 없고, 파일 크기는 내 기기의 성능에 따라 달라집니다.
